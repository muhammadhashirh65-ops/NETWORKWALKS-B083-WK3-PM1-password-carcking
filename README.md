# NETWORKWALKS-B083-WK3-PM1-password-carcking
Recovered the open password of a locked PDF by extracting its hash with OnlineHashCrack's PDF Hash Extractor, then cracking it using John the Ripper (via the Johnny GUI). Verified the password by unlocking the PDF in Adobe Acrobat Reader, confirming success via the "flag captured" message. Screenshots document each step of the process.
